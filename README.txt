AL-EMAN ERP - نسخة مطورة

تشغيل سريع:
1) افتح index.html.
2) جرّب: owner@aleman.local / Owner@123
3) من صاحب الشركة أو مدير الشركة يمكن إضافة موظف مع حساب دخول ومرتب وبدلات وخصومات.

الجديد في النسخة:
- معالجة مشكلة اللوجو الأبيض: كل أماكن الشعار بخلفية داكنة/متدرجة.
- HR كامل: موظفين، حسابات دخول، وظيفة، قسم، مرتب، بدلات، خصومات، صافي، حضور وانصراف.
- Accounts كامل: فواتير، سندات قبض، مصروفات، مديونيات، رصيد تقديري.
- طباعة فواتير وعقود بتنسيق رسمي.
- تصدير Excel/CSV من العملاء، الموظفين، الفواتير، الحسابات، المخازن.
- Supabase schema شامل + Realtime tables لكل الأقسام.
- UI عربي RTL احترافي ومتجاوب للموبايل.

ربط Supabase:
- شغّل database/supabase_schema.sql داخل SQL Editor.
- عدّل js/supabase-config.js ببيانات مشروعك.
