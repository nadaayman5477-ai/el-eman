شركة الإيمان لتوريد الأسماك - ERP Prototype

طريقة التشغيل:
1) افتح index.html مباشرة من المتصفح.
2) جرّب الدخول بحساب Owner:
   owner@aleman.local / Owner@123
3) الحسابات التجريبية موجودة في js/data.js
4) اربط Supabase من js/supabase-config.js بعد تشغيل database/supabase_schema.sql داخل Supabase SQL Editor.

الخصائص:
- UI عربي RTL احترافي ومناسب للموبايل.
- صلاحيات حسب الوظيفة.
- إدارة العملاء والمنتجات والطلبات والتوصيل والمخازن والفواتير والعقود والشكاوى.
- طباعة فاتورة وعقد.
- تصدير Excel من صفحات العملاء والأسعار.
- قاعدة بيانات Supabase بجداول Realtime.
