AL-EMAN ERP PRO V3 COMPLETE
شركة الإيمان لتوريد الأسماك الطازجة والمجمدة

طريقة التشغيل:
1) افتح index.html مباشرة في المتصفح.
2) ادخل بأي حساب تجريبي. كلمة المرور الافتراضية 123456.
3) لتشغيل Supabase: نفذ الملفات داخل database بالترتيب:
   01_full_setup.sql
   02_erp_logic_upgrade.sql
4) بيانات الربط موجودة في js/supabase-config.js.

الجديد في V3:
- الطلبية تحتوي أصناف وكميات وأسعار.
- اعتماد الطلب يخصم المخزون ويولد فاتورة.
- منع اعتماد طلب لو المخزون غير كافي.
- إلغاء الطلب المعتمد يرجع المخزون.
- طباعة فاتورة رسمية، أمر توريد، عقد توريد بصيغة منظمة.
- HR كامل: إضافة موظف، حساب دخول، وظيفة، صلاحية، مرتب، حضور، خصومات، مسير مرتبات.
- حسابات: فواتير، مدفوعات، مصروفات، متبقيات.
- مخازن: وارد وصادر وحد تنبيه وحركات مخزون.
- تصدير Excel شامل + Price List.
- UI عربي RTL احترافي للموبايل والديسكتوب.

ملاحظة:
هذه نسخة Frontend Prototype متقدمة مع LocalStorage + ملفات Supabase جاهزة.
عند الإنتاج، يفضل ربط عمليات الإنشاء والتعديل مباشرة بجداول Supabase مع RLS صارمة.
